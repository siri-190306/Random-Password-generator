# 🔐 Random Password Generator

A simple, colorful, and responsive Random Password Generator created using HTML, CSS, and JavaScript.

## ✨ Features

- Generate random passwords instantly
- Choose password length from 4 to 30 characters
- Select uppercase letters and lowercase letters
- Include numbers and special symbols
- Copy passwords to the clipboard
- Display an error when no character type is selected
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Choose your preferred password length and character types.
6. Click **Generate Password**.
7. Click the copy button to copy your password.
